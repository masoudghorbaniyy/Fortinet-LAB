\# Fortinet LAB



This is a personal Fortinet lab built in EVE-NG to gain hands-on experience with FortiGate, FortiManager, and FortiAnalyzer.



\## Lab Features

\- MPLS + Internet underlay (BGP)

\- Hub-and-spoke IPsec VPN

\- SD-WAN configuration

\- Centralized management (FortiManager)

\- Centralized logging (FortiAnalyzer)



\## Purpose

This lab is designed to simulate a real-world enterprise network and improve troubleshooting and deployment skills.

Also, quick tip from my setup—running FortiManager and FortiAnalyzer on ESXi gave me much better performance compared to EVE-NG.


\## How to use

1\. Import the .unl file into EVE-NG

2\. Load device configurations

3\. Start the topology and test connectivity
